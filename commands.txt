===>Drizzle<===
Create migration script:
npx drizzle-kit generate

Run migration script:
npx drizzle-kit migrate

===>Run Scripts<===
npx tsx scripts/test-db.ts
npx tsx scripts/test-auth-service.ts

Run one file with npx vitest run test/routes/auth/login.test.ts, or one test by name with -t "wrong password".
